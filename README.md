# TURTLE Hatchling 

This repository contains the hardware designs and software source code for the 1st place winning robot in the Texas A&M University Robotics Team and Leadership Experience (TURTLE) Hatchling competition.

## Overview
This project features an ESP32-based robot built from the ground up to tackle the Hatchling competition challenges. The system integrates custom 3D-modeled components, intricate circuitry, and embedded logic to execute its tasks efficiently. 

## Hardware Specifications
* **Microcontroller:** ESP32
* **Mechanical Design:** Custom 3D modeled chassis using SolidWorks
* **Electronics:** Custom wiring harness and power distribution

## Software Architecture
* **Language:** C++
* **Functionality:** Implements motor control, sensor polling, and core embedded logic on the ESP32 microarchitecture.
